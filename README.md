Project Description

QuickChat is a Java messaging application developed for the Programming POE.

Features

 User registration and login.
 Sending messages.
 Viewing sent messages.
 Managing stored messages.
 Searching messages.
 Deleting messages.

Technologies

 Java
 NetBeans
 Maven
 JUnit 5

How to Run
Open the project in NetBeans and run the POE_Part1 class.
